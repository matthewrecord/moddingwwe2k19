# Instructions for Gemini CLI

**Start with `STATE.md` (one screen). The write-up is `writeup/*.md` on GitHub.** Read `writeup/Status.md` (sections 1-3)
and `WORKFLOW.md` before doing anything. Work on a `gemini/<task>` branch, never on `main`. Pull before editing; push your
branch when done. Do not modify game files; propose changes in a branch for Claude to review. Plain language for Matthew;
paths go in files.
