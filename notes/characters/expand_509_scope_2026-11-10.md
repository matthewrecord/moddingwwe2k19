## Structures (WWE2K19_x64.exe, Steam build of 2021-03-30)
- **Main (file-loaded) pofo array**: pointer at 0x1425e69b0, 509 x 0x1E4 (484) bytes. ~700 code refs read the
  pointer (index*0x1E4 + [ptr]) -> unaffected by moving/enlarging the array.
- **Per-save copies**: pointer 0x1425e69a8, 3 blocks of 0x1EA9C8 bytes; pofo i at block + 8 + i*0x1E4 (i < 0x1FD).
  Data after the pofos sits at fixed block offset 0x3C260 (89 code sites) and beyond -> enlarging save copies =
  patching dozens of offsets. AVOID.
- Fetch `0x140965710(idx, slot)`: save copy if slot block exists and idx < 0x1FD, **else main array** -> slots >= 509
  would naturally come from the main array (file-defined; not editable in-game / by CCT save injection).
- Loader `~0x1404ce4f0`: allocates 2 x 0x3C254 (509 pofos) [+ 0x3C260 variants], 0x1AE768 (= 509 x 3464: movesets),
  then loops r12d = 0x1FD. Other 0x3C254 allocs: 0x1404ce8ad, 0x140cf882b, 0x140d245d2, 0x140d7880a, 0x140e65bb0,
  0x140e83524; 0x1AE768: 0x1404ce6f6, 0x1404ce8be, 0x140b0d4a0, 0x140b0d62c, 0x140b102d1.
- id -> pofo index map: table 0x1425beb60 (0x400 ints), flag 0x1425beb50; `0x1404c97d0`. Callers reject index > 0x1FC.
- Constant counts in code: 0x1FC x403, 0x1FD x336 (most unrelated), 0x1EA9C8 x33, 0x3C254 x8, 0x1AE768 x6.

## Step 1c (14:20): long tail + map tables
- id->index map 0x1425beb60 (1024 ints, init -1 at 0x14190fc23) and **index->id table 0x1425bfb60 = exactly 509
  ints** (static .data, other data follows at 0x1425c0354), init to 0x400 at 0x14190fc79. Refs: builder 0x14190fc86,
  reader `0x1404c98d0` (cap 0x1FD at 0x1404c98e9). Must be relocated to a bigger buffer (2 refs).
- Profile loading is async: 0x14190fbf0 queues "/PR%02d/DAT" (and PRO, MVS) for up to 0x81 patch packages; rows are
  consumed in a completion callback (not yet located; dynamic watchpoint on the map is the quickest way).
- All 0x1FC/0x1FD immediates in code (`cap_constant_sites.txt`): 173 loop bounds over the slots, 48 "jae" + 6 "ja"
  checks, ~440 movs (mostly unrelated). Unpatched loops would silently skip slots >= 509 (feature-level omissions
  rather than crashes): expect several boot/check rounds.
- Matthew 14:17: pofos and movesets are injected live by CCT today. For new slots they go into the profile tables
  (profile_dat/mvs/pro rows) loaded at boot, as PPX and the vanilla roster do; live injection later via our DLL.
