ARENA PACK (moddingwwe2k19) - 2026-11-14
=========================================
Everything from the arena rebuild (Nov 2026) as one drag-and-drop folder:
387 files (178 new, 209 replacements), 2.0 GB. MANIFEST.md5 lists every file with its MD5.

REQUIREMENTS (the base this was built and tested on)
- Clean WWE 2K19 (Steam).
- Modding Militia "Arena Essential Pack" (81 arenas), installed through Genesis,
  including "WWE 2K19 Unpacked Arena Graphics" and "SuperString".
- Install this pack BEFORE any other mod that edits the arena tables (see "Whole files" below).

INSTALL
1. Copy the "pac" and "mods" folders from here into the game folder
   (...\steamapps\common\WWE 2K19\). Overwrite when asked.
2. Rebuild the chunk file (chunk0.def) the way you normally do, so the 178 new files get indexed.
3. Start the game. Check: Exhibition > Select Arena.
Do not copy MANIFEST.md5 or this README into the game folder.
Keep nothing else (backups, work folders) inside the game folder: a chunk rebuild indexes everything there.

SHARED CHANGES WORTH KNOWING
- Crowd 3 = AEW crowd shirts (crowd 3 was unused by any arena before).
- Rope 7 = AEW rope. All AEW arenas use misc01 "Live" 7 (no WWE "W LIVE" bug).
- Battleground '15's "ppv_logo" file (141 -Battleground '15.pac) carries the NJPW crest: the pack's
  file labels for slots 5 and 141 are swapped, and this is the one Tokyo Dome reads.

KNOWN GAPS
- Tokyo Dome: no NJPW locator/nameplate/match result yet; its match card is the shared generic card (shows names).
- AEW x NJPW Forbidden Door (slot 4) not included: needs the 2K15-2K18 Arena Port and Titavius'
  "AEW Dynamite - LA Forum '22" entrance pieces.
- WrestleMania 31 was tried in 140 and removed (the original stays in slot 105).
